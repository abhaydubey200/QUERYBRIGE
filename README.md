# Overview

QueryBridge is an enterprise AI analytics platform that enables business users to interact with enterprise data using natural language instead of writing SQL.

Users can ask questions such as:

> "Show total sales by region for the last 12 months."

> "Which products generated the highest profit in Q1?"

> "Compare this month's revenue with last year."

The platform understands business intent, generates validated SQL queries, executes them against enterprise databases, explains the results, and automatically creates charts and dashboards.

QueryBridge bridges the gap between business users and enterprise data by combining Large Language Models, semantic metadata, SQL validation, and visualization into a single intelligent analytics platform.

---

# Problem Statement

Modern organizations store massive amounts of data across multiple databases, but accessing this information often requires SQL expertise.

Common challenges include:

- Business users cannot write SQL.
- Analysts spend significant time answering repetitive data requests.
- SQL generated by AI may be incorrect or unsafe.
- Multiple database systems create inconsistent query experiences.
- Lack of governance increases security risks.
- No explainability for AI-generated queries.
- Slow turnaround for ad-hoc analytics.

---

# Solution

QueryBridge provides a secure AI-powered analytics layer that converts natural language into validated SQL, executes queries against enterprise databases, and presents business insights through interactive visualizations.

The platform combines:

- Large Language Models
- Semantic Metadata Layer
- SQL Validation Engine
- Business Rules Engine
- Visualization Engine
- AI Explanation Layer
- Enterprise Security Controls

This enables organizations to democratize data access without compromising governance or accuracy.

# Core Features

## Natural Language to SQL

Convert plain English into optimized SQL.

Example:

```
Question

Top 10 customers by revenue this year

↓

Generated SQL

SELECT customer_name,
SUM(revenue)
FROM sales
WHERE order_date >= '2026-01-01'
GROUP BY customer_name
ORDER BY revenue DESC
LIMIT 10;
```


Backend

```bash

pip install -r requirements.txt
```

Frontend

```bash
cd frontend

npm install
```

Run Backend

```bash
uvicorn app.main:app --reload
```

Run Frontend

```bash
npm run dev
```
